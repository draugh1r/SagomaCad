# UI M0

I token di colore, spaziatura e dimensione sono in `src/ui/theme.hpp`, per i temi `dark` e `light`. La shell SagomaCad mostra una barra superiore, browser, viewport, proprietà e timeline. Nel viewport la griglia e gli assi sono disegnati con primitive Dear ImGui renderizzate dal backend OpenGL. I pannelli occupano nodi docking fissi senza barre delle schede; i titoli delle sezioni sono etichette interne. Il viewport non ha titolo. Inter usa l'intervallo U+0020–U+024F, che comprende Latin-1 e Latin Extended A/B.
